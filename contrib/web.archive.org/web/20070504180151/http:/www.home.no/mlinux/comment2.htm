BL and SVGAlib

From Steven (The creator of BasicLinux)

I see you have a section about installing libvga and libvga applications. People who want libvga instead of X should consider using BL1 instead of BL3. B1 uses the same library as BL3 (libc5) and is preconfigured to run libvga applications. IIRC it also has the ncurses library, which you recommend as a BL3 add-on.

To update BL1, you could copy executables (busybox, links, etc.) from BL3. You could also copy the 2.2.26 kernel (with modules) from BL3.

Perhaps someone would like to create a BL1+ with 2.2.26 kernel, newer busybox, ae editor and the libvga version of links2? It could be released as a fs.img.

Cheers,
Steven

Filling out the background.

From Bryan Henderson (maintainer of Netpbm)

The way to fill the background with black using Netpbm is to use the program 'pambackground', which is quite new. You have to make your outline go all the way around the subject to use that (i.e. you need a horizontal black line at the bottom).
