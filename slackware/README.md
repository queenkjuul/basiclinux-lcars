# Slackware Mirrors

## Slackware 4.0

.tgz packages from Slackware 4.0 are all included already in `livecd/packages/slackware-4.0`.

Additional sources and support files are included for posterity, and for potential future inclusion in BasicLinux-LCARS.

Slackware 4.0 packages are, broadly, compatible with BasicLinux,
though many of them require additional libraries to be installed first - see the BasicLinux documentation

## Slackware 9.0

Slackware 9.0 used to be mirrored here. It is no longer, as it isn't actually compatible with BL3. Instead, the `glibc-2.3.1` package (which is verified compatible with BL3) is included in `/livecd/extras/slackware-9.0`

If you need files from Slackware 9.0 for some reason, it is still mirrored at [https://github.com/queenkjuul/slackware-9.0](https://github.com/queenkjuul/slackware-9.0)
